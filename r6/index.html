About this map

Consulate, as it exists in game today. The floor plans are Ubisoft's own blueprints from the June 2023 rework (Y8S2, Dread Factor), which rebuilt the map from scratch. The Year 10 Season 3 pass in September 2025 was a visual modernisation — 4K textures, lighting, shadows, and a few new destructible props. It did not change the layout, so these are current.

All four floors are the same camera at the same position, so they line up exactly. Switching floors peels one layer off the same building rather than swapping to a different picture.

On orientation: Siege gives players no compass, so there is no in‑game north to align to. This uses Ubisoft's canonical blueprint orientation — the one every community resource and the in‑game tactical map share — with the main entrance at the bottom.

Controls: drag to pan, pinch or scroll to zoom, double‑tap to reset. Keys 1–4 or ↑/↓ change floor.

On a phone: add this to your home screen and it opens with no browser bars at all.
